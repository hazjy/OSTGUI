# OSTGUI v1.8.1 —— 联机页重做与术语统一

> 适用版本：v1.8.1（对比 v1.8.0）

## 新增

- **联机方式改名**：DLL 注入 → **宿主会话**、AppID Changer → **文件会话**、内核原生 → **命令行会话**。界面文案、代码注释与开发文档同步统一。
- **会话身份选择会记住**：默认身份／自定义身份、以及自定义的 AppID 会写进配置，重开程序保持上次选择。
- **启动前置检查**：宿主会话与文件会话各显示三项状态——Steam 是否运行、内核是否已安装、游戏是否已入库。仅作提示，不拦截启动。

## 修复与改进

- 前置检查的「入库」项改为仅在查询过 AppID 之后才判定，未查询时显示「未查询」，不再把半截输入当成结论。
- 前置检查改为每项一块、横排一行，并修掉上一版该区域整体空白的问题（AOT 下嵌套类型的绑定不可靠，改用顶层属性）。
- 命令行会话页补一行「更推荐使用「宿主会话」」提示，字号与修改器页副标题一致；撤掉该页多余的状态行与说明。

## 文档

- 精简 14 份开发文档（去过程与历史，事实、判据与数值保留）。
- `REF-联机.md` 按新命名重写章节；退役 `UBISOFT-NOTES.md`（免育碧功能已挂起）；旧版更新说明归入 `v1.3.x-v1.6.x/` 子目录。

## 升级方式

- 覆盖旧版程序目录即可（新旧可以共存）。
- 内核请按需单独更新：本版与 v1.2.0 内核搭配使用（联机的宿主会话依赖内核的会话身份支持）。
