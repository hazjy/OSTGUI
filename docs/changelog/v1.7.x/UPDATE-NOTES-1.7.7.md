# OSTGUI v1.7.7 更新说明

> 适用版本：v1.7.7（对比上一版本 1.7.6）


## 修复：
- **免 Steam 部署**不再会误删游戏自带的 Plugins 目录
- 入库不再改动 steamtools.lua
- 修复清单源 **「上次更新时间」** 显示不准确

## 更改：
- **侧边栏宽度点**「更改」后不再清空输入框
- 免 Steam 页「部署日志」栏现在能看到全部部署细节，而且顺序正确
- 设置页日志栏改为显示全量日志（去掉 2000 行显示上限）
- 主页状态不再固定显示「就绪」，而是按实际健康状态显示

## 升级方式
- 覆盖旧版程序目录即可（也可以新旧共存）
