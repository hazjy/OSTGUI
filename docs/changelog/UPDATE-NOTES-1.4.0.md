## 新功能

- **联机页：自定义联机会话身份**。联机页新增「默认身份（480）／自定义身份」选择与「会话身份 AppID」输入框：
  - 默认身份 = 原有行为（Spacewar 480）；
  - 自定义身份 = 启动参数改为 `-onlinefix=<你填的 AppID>`，可挑一个带 Steam Input 手柄配置的免费联机 AppID，解决 480 无手柄配置的问题；
  - **对端必须使用相同会话身份**；非法值（非十进制 / 0）会被拦下并提示（内核遇到非法值会静默回落 480）；
  - 需内核 **ZSteamTool v1.1.0+**（旧内核不认该参数）。
- **设置页：D 加密模式开关**。新增「D 加密模式」卡片（普通模式 / 兼容模式），直接读写内核配置 `<Steam>\opensteamtool.toml` 的 `[denuvo] mode`，**改完立即生效，无需重启 Steam**（内核热重载），卡片下方显示配置文件路径便于手改：
  - **普通模式（默认，推荐）**：D 加密游戏只在授权握手期间使用票据身份，其余时间按你**当前登录账号**运行 → 游戏的存档 / 云存档 / 设置绑定你自己的账号，不会出现"读不到自己存档"；
  - **兼容模式**：整场按票据所属账号运行，供少数仍会复验身份的严格标题使用；**代价是该游戏的存档 / 云存档会绑定出票账号**。
- **模拟器页：免育碧（实验性）**。新增「免Steam／免育碧」分段，可自动探测 `upc_r2` / `uplay_r2` / `uplaypc_r2` 系 loader 并替换为内嵌 Goldberg R2、写入 `uplay_r2.ini`，支持还原。
  - 仅支持**传统单 loader 型** R2 游戏；多组件 UC 栈（如 UNO）经实测不兼容，面板内已标注实验性。

## 体验优化

- **清单源行样式**：源名称与用途同行显示（`MHub | 清单源`、`Sudama | 密钥源`），时间文案统一为「上次更新：…」；Sudama 名称去掉"库"字。内置源的名称与说明改为以程序为准，旧配置里的历史文案会在加载时自动纠正，无需手动清理配置。
- **S.A.C 页更名为「模拟器」**（侧边栏与页面标题同步），复用分段切换组织免 Steam / 免育碧两块内容。
- 补齐页面级焦点锚点（免育碧面板），修复"点击空白误激活输入框 / 无法取消激活"。

## 修复

- **入库链路两处容错**：
  - SteamCMD 信息查询失败时自动重试（最多 3 次，递增延迟），偶发网络失败不再打断入库前置步骤；
  - 清单写入 depotcache 改为逐份容错并汇总警告，避免单份失败导致整轮中断、留下"config 有、根目录没有"的半成品（该状态会表现为下载报 No connection）。

## 配套内核：ZSteamTool v1.1.0

本版 GUI 的联机会话身份与 D 加密模式开关都依赖同一批发布的内核 **[ZSteamTool v1.1.0](https://github.com/hazjy/ZSteamTool/releases)**（Release 内含 `Debug\` / `Release\` 两套三 DLL + 配置模板）。要点：

- **D 加密模式（`[denuvo] mode`）**：`normal`（默认）只在 D 加密授权握手期间使用票据身份，其余时间按你**当前登录的账号**运行 → 游戏存档 / 云存档 / 设置绑定你自己的账号；`compat` 整场按票据账号运行，供少数复验身份的严格标题使用（代价是该游戏存档绑到出票账号）。**修复了此前 D 加密游戏"读不到自己存档"的问题**；
- **联机会话身份**：支持 `-onlinefix=<appid>` 自定义会话身份（默认 480），联机页已接入；
- **下载链路**：请求码收口环境下以「清单投喂 depotcache」为正路，858 所有权票据增加 Forge 兜底，请求码等待窗口放宽到 30s；
- **升级方式**：替换 Steam 根目录下的 `OpenSteamTool.dll` / `dwmapi.dll` / `xinput1_4.dll`（先用 `Release\`，排障再用 `Debug\`）；已有的 `opensteamtool.toml` **不需要替换**，缺少 `[denuvo]` 段时默认即 `normal`。

## 说明

- 内置清单源维持两个：**MHub**（清单）与 **Sudama**（密钥 / 访问令牌）；
- 自定义会话身份与 D 加密模式开关都依赖 **ZSteamTool v1.1.0+**；使用旧内核时前者会被忽略，后者不影响运行；
- 会话身份选择**不随应用保存**，切走再回来会回到「默认身份（480）」；
- 免育碧部署会备份原文件为 `.bak`，可用面板中的还原按钮回滚；重复部署会覆盖备份，请勿在已部署状态下反复点部署。

## 升级方式

下载新版解压覆盖旧版程序文件即可。配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。
