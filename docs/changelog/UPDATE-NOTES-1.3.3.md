# OSTGUI v1.3.3 更新说明

> 适用版本：v1.3.3（对比上一版本 1.3.2）

## 新功能
- **DLC 名称实时获取**：入库信息对话框中 DLC 名单改为实时后台获取，不再参与缓存，对话框立即打开、DLC 区后台加载；
- **库页显示名优化**：库页显示名改为纯缓存读取 + 主游戏后台静默补名，联机页显示名与名称缓存解耦；
- **Sudama 缓存时间显示**：设置页显示 Sudama 缓存上次刷新/导入距今时间（文件 mtime 推算，每分钟自动刷新）；缓存时间改为直接显示更新日期+小时，去掉分钟级定时刷新；缓存时间小字移到 Sudama 源行内；
- **API Key 时间显示**：需 token 的源（MHub / GitHub）显示 API Key 上次设置时间；
- **Sudama 缓存策略调整**：去掉 24h 自动刷新——缓存存在即用，仅手动刷新/导入更新；
- **侧边栏默认宽度**：默认宽度从 360 调整为 200，可配置范围扩大至 150–600。

## 修复

- **DLC 名称读取**：steamcmd 不提供 DLC 名字（实测空壳），兜底官方 appdetails（8s 截断）；
- **名称缓存**：缓存 Set 加 30 天 TTL 守护——有效期内不覆盖，改名游戏不再被查询流程刷新；
- **API Key / Token 时间戳**：上次更新时间改失焦记录（一次、幂等），消除逐键重建导致的显示不稳定；仅在实际值变化时记录；
- **空 Lua 目录**：跳过主游戏补名，修复 CS8604 null 警告；
- **构建脚本**：兜底嵌套目录产物——先镜像回规范路径再清理，避免误删唯一副本；构建后同步嵌套副本中更新的产物回规范路径。

## 维护与内部整理
- 构建成功后自动清理 `main/.build` 和 `NoSteamLauncher/.build` 冗余副本（WindowsAppSDK 嵌套拷贝怪癖产物）；
- 清理 GitHub Auiowu 源相关死代码；LuaBuilder DLC 段查 Sudama 写 key；
- 搜索框去掉固定高度，自适应内容；
- 文档整理：更新日志与开发文档分文件夹（`changelog/` 与 `dev/`），新增多智能体变更台账。

## 说明
- Sudama 密钥库不再自动 24h 刷新，如需更新请在设置页手动点击刷新。
---

## 升级方式

下载新版解压覆盖旧版程序文件即可。配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。
