# OSTGUI v1.7.8 更新说明

> 适用版本：v1.7.8（对比上一版本 1.7.7）


## 修复：
- **虚幻引擎（UE）游戏的免 Steam 部署**不再漏掉 `Engine\Binaries\ThirdParty\Steamworks\Steamv<版本>\Win64\` 里的 `steam_api64.dll` —— 此前只处理 EXE 同目录那份，会出现「提示部署成功、游戏仍要求 Steam」
- **一键还原**同步覆盖上述目录，不再残留模拟器文件
- 还原时偶发的「文件被占用、无法替换」不再需要手动再点一次：启动瞬间的短时占用会自动重试

## 更改：
- **脱壳与模拟器组件全部跟到上游最新**：GSE 模拟器（gbe_fork）、Steamless（反汇编器已换为 Iced）、SteamAPICheckBypass —— 对较新的 SteamStub 壳与更多游戏的支持随之更新

## 说明：
- 免 Steam 部署后，该游戏**无法再用 GUI 的 480 联机**（模拟器顶掉了游戏的 Steam 接口）—— 想联机请先「一键还原」；部署后要在模拟器世界里联机需另找联机补丁，本项目不提供

## 升级方式
- 覆盖旧版程序目录即可（也可以新旧共存）
