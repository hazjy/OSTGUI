# OSTGUI v1.7.5 更新说明

> 适用版本：v1.7.5（对比上一版本 1.7.0）

## 特别说明：

需 **[ZSteamTool v1.1.3](https://github.com/hazjy/ZSteamTool/releases) 及以上**

本版改为**原生编译（Native AOT）**：程序编译为原生代码，不再依赖 .NET 运行时，解压即用。

## 运行方式与性能

- **原生编译**：不再依赖 .NET 运行时，启动阶段无需 JIT 预热；仍为自包含、免安装，解压覆盖旧版即可。
- **内存占用下降**：启动后工作集约 49 MB（上一版约 109 MB）；连续切换页面 20 次后约 254 MB（上一版约 273 MB）。
- **分发包体积减小**：约 82 MB 降至约 36 MB（原生编译去掉了随包的 .NET 运行时文件）。

## 联机

- **修复：查不到已安装游戏的主程序**。原规则只检查游戏目录顶层，遇到主程序位于子目录（如 `bin64\`）或程序名与目录名不一致的游戏，会直接判定「未找到」。现按可信度分三档定位：与目录同名的主程序 → 目录顶层体积最大的可执行文件 → 四级子目录内体积最大的可执行文件（已排除崩溃处理器、卸载器与运行库安装器）。
- **启动失败会说明原因**：宿主进程启动后立即退出时，提示会给出退出码与具体原因，并指明日志位置；不再出现「界面提示成功、实际未生效」的情况。

## 日志

- **「日志文件保留行数」现在真正生效**：日志超过设定行数时直接裁剪文件、只保留最近内容，不再出现设置不生效、文件持续增大的情况。
- **日志栏只渲染尾部 2000 行**：长时间运行不再因日志栏累积内容而占用内存（内部仍保留完整内容，可随时复制）。
- **「复制全部」复制完整日志**，并回报已复制的行数。
- **取消「诊断 / 流水账」两条通道**：日志文件与日志栏显示同一份内容（上一版将日常流水账移入设置页，本版回到一处，便于对照）。

## 提示与文案

- **即时反馈改用应用内通知**：复制、切换、绑定、启动，以及「请先填写游戏 AppID」这类校验提示，改为窗口顶部的一条通知，不再进入 Windows 通知中心。失败与耗时操作的结果仍使用系统通知，便于窗口不在前台时也能看到。
- **通知浮层改为不透明底色，并移至窗口右上角**：压在大号标题上时不再透出底下的文字。
- **界面文案全面书面化**：通知、校验提示、控件说明与日志用语统一为书面表述（统一「未／无法／不能」、「已 + 动词」、「请先 + 动词」等口径）。

## 修复

- **入库管理**：游戏名称、AppID、来源标签变化后卡片不刷新的问题。
- **联机**：主程序位于子目录的游戏无法定位（例如红色沙漠，AppID 3321460）。
- 清理若干已失效的界面资源与死代码。

## 注意事项


- 覆盖升级前请先**退出正在运行的程序**，避免文件被占用导致替换失败。
- 配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。

---

## 升级方式

下载新版解压覆盖旧版程序文件即可。配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。
