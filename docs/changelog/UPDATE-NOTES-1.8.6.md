# OSTGUI v1.8.6 —— Lua 编辑器与设置页修复

> 对比 v1.8.5

## 修复

- **Lua 编辑器随窗口收缩**：窗口变矮时，底部状态行和编辑框下边框不再被裁掉。
- **Lua 编辑器不再被拽回光标行**：往上翻着看代码时，打字触发的那次语法上色不会再把视口跳回光标所在行。
- **设置页粘贴密钥**：MHub / Hubcap 的 API Key 用右键菜单粘贴时，也会正常刷新「上次更新」时间。

## 升级方式

- 覆盖旧版程序目录即可。
- 内核无需更新。
