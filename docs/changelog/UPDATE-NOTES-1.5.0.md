# OSTGUI v1.5.0 更新说明

> 适用版本：v1.5.0（对比上一版本 1.4.1）

## 特别说明：请配套升级内核

本版配套内核 **[ZSteamTool v1.1.3](https://github.com/hazjy/ZSteamTool/releases)**，它修掉了 `-onlinefix` 会话状态的跨启动残留；「信息」页显示的内核版本也要求 v1.1.3 及以后。

## 新功能

- **联机页新增第二条启动方式：「其他 → DLL 注入」**。它不依赖内核的 `-onlinefix` 参数——由一个独立宿主进程把游戏以 480 身份原生拉起，游戏自己的 AppID / 大厅 / P2P 证书 / 叠加层天然一致：
  - 只需填**游戏 AppID**，点「查询」自动带出程序路径；协议 AppID 默认 480，也可自定义；
  - 启动/停止是卡片上的两个图标按钮。
- **「信息」独立成页**：侧边栏「信息」不再是弹窗，改为独立页面，显示 **GUI 版本**与**内核版本**（内核版本直接读已安装 `OpenSteamTool.dll` 自带的版本信息，需内核 v1.1.3+）。

## 修复
- 无



## 说明

- 联机的两条路线**不要同时使用**：走「内核原生」就别开 DLL 注入，反之亦然。
- 480 方案下双方都以 Spacewar(480) 身份运行，好友列表里互相显示"正在玩 480"是正常现象。

---

## 升级方式

下载新版解压覆盖旧版程序文件即可。配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。
