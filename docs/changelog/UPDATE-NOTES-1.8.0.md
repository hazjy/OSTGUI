# OSTGUI v1.8.0 —— 适配新版 Steam（请同步更新内核）

> 适用版本：v1.8.0（对比上一版本 1.7.9）

## 重要：只升级 GUI 不足以恢复功能，内核必须同步更新

Steam 客户端已于 **2026-10-14** 更新。旧版内核（ZSteamTool v1.1.3 及更早）在该版本上会导致 **Steam 启动约 5 秒后自行退出，且已入库游戏全部显示未解锁**。此问题与图形界面无关，只能通过更换内核解决。

- 内核下载（ZSteamTool v1.1.4，已适配新版 Steam）：https://github.com/hazjy/ZSteamTool/releases/latest
- **旧版 OSTGUI 的「检查更新」只检查自身**，不会提示内核有新版本 —— 升级到本版后，GUI 与内核会一并检查。

## 新增

- **「检查更新」现在同时检查内核**：一次比对本机 GUI、本机内核与两个仓库各自的最新发布版本，结果合并为同一条系统通知：
  - 两者均有更新：提示「发现内核新版本 vX.X.X 和 GUI 新版本 vX.X.X，当前版本 vX.X.X 和 vX.X.X」，并给出「前往内核发布页」「前往 GUI 发布页」两个按钮；
  - 仅一方有更新：单条提示与对应按钮；
  - 手动检查且均无更新：「关于」弹窗内以小字提示「已是最新」。

## 说明

- 内核版本取自本机已部署的 `OpenSteamTool.dll` 的版本信息；未安装内核时该项不参与比对。
- 自动检查仍在启动 5 秒后进行，受设置页「接收更新推送」控制；同一版本只提示一次，GUI 与内核分别记账。
- 内核与 GUI 需分别下载替换，本版不提供自动下载。

## 升级方式

- 覆盖旧版程序目录即可（也可以新旧共存）；**内核请按上文单独更新**。
