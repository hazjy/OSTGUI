# OSTGUI v1.7.0 更新说明

> 适用版本：v1.7.0（对比上一版本 1.6.2）

## 特别说明：

需 **[ZSteamTool v1.1.3](https://github.com/hazjy/ZSteamTool/releases) 及以上**（本轮未改动内核）

## 修改器（新增页面）

- **搜索风灵月影修改器**：走站点官方 RSS 取结果，只列正文条目，不会混进侧栏的推荐 / 热门。
- **一键下载**：自动跟随跳转、带上防盗链所需来源，压缩包自动解压；下载进度显示在状态行。
- **「已下载」列表**：按索引管理（不再扫目录猜），可过滤。
- **一键更新**：直接取官方最新版覆盖，并同步索引；已是最新会明确提示，不会白下一遍。
- **「更多」菜单**：复制名称（exe 完整文件名）/ 更新 / 删除（红字，删除会连带移除指向它的绑定）。

## 进程绑定（新增）

- **随游戏启停**：游戏主程序一启动就自动运行对应修改器，游戏退出就结束它（只结束它自己启动的那个）。
- **按名称绑定**：绑定记录的是修改器名称，实际文件按名称查索引——更新换了文件名也不会失效。
- **后台监控进程**：GUI 关掉后绑定仍然生效；页面上的「运行 / 停止」两个按钮控制它，状态实时跟随（在任务管理器里结束它，界面也会跟着变）。
- 监控进程占用从约 107 MB 降到约 40 MB。

## 成就

- **成就编辑**：左侧列表 = 入库档（lua）+ 客户端认为拥有的游戏，两者可分别勾选（按页记住）；选中游戏后可编辑成就解锁状态，**先写本地留底**，再手动「保存到 Steam」写回（写入会进 Valve，重启 Steam 后仍在）。
- **按名称 / 描述过滤**成就列表；页头「刷新」可重读当前游戏。
- **写入失败有诊断**：失败会给出 E1 / E2 / E3 提示（例如部分育碧游戏），日志里有具体原因。
- **左侧列表加缓存**：重开应用秒开，也不再每次启动都起一次查询子进程；lua 档或 `appinfo.vdf` 有变化会自动重扫，「刷新」可强制重扫。

## 界面

- **应用内通知**：窗口顶部一条细提示（例如「更多 → 复制名称」会给出反馈），不再只依赖系统通知。
- 修改器页文案精简；成就页左侧列表宽度与修改器页对齐。

## 其它

- **日志系统重做**：日志文件只留崩溃 / 诊断（启动退出、异常全栈、外部失败、关键状态变化），日常流水账移到设置页「运行时日志」；文件按大小轮转，多个子进程同时写不再丢行；崩溃钩子补全（UI 线程 / AppDomain / 任务异常）。

## 修复

- **监控进程一运行就死**（子进程里读主窗口对象触发空引用；现在子进程不再碰 UI，崩了也会写日志）。
- 搜索结果与「已下载」列表互相串号；切回搜索页会重复联网抓取；搜索结果里混入站点侧栏推荐。
- 下载时不显示进度（该站响应没有长度，改为按已下载大小显示）。
- 绑定按名称查不到（索引里的名字不带扩展名，而复制出来的是带 `.exe` 的文件名）。
- 多个进程同时写日志时的静默丢行。

## 注意事项

- **旧绑定需要重新添加一次**：绑定文件的存放位置与格式都变了（现在在 `%LOCALAPPDATA%\OSTGUI\bindings.json`，且按修改器名称记录）。
- 修改器是**第三方程序**（来自 flingtrainer.com），杀软可能误报；只有你点「启动」或绑定生效时才会运行。
- 首次进成就页仍会完整扫一遍并写入缓存，之后重开才是秒开。

---

## 升级方式

下载新版解压覆盖旧版程序文件即可。配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。
