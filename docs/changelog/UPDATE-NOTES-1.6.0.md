# OSTGUI v1.6.0 更新说明

> 适用版本：v1.6.0（对比上一版本 1.5.0）

## 特别说明：请配套内核 ZSteamTool v1.1.3+

本版**要求内核 [ZSteamTool v1.1.3](https://github.com/hazjy/ZSteamTool/releases) 及以上**。原因：联机相关的改动依赖它自 v1.1.3 起的行为——`-onlinefix` 会话状态随游戏进程退出即清空；另外「信息」页读内核版本号也要求 v1.1.3 及以后（更早的内核 DLL 没带版本信息）。

## 视觉：亚克力效果

窗口背景不再只有云母一种选择，**设置 → 外观设置 → 显示效果**里可以切换三档：

- **无**：不透明纯色底，最省电、最稳
- **云母**：Windows 11 的云母材质，桌面壁纸只透一点点
- **亚克力**：壁纸重度模糊后透出来，观感更"玻璃"，**本版默认**

切换即时生效、记在配置里，重开还是上次那档。云母/亚克力需要 Windows 11（亚克力需 22H2 及以上），系统不支持时自动回落纯色底，不会出错。

## 联机：新增「AppID Changer」方式

联机页「其他」下拉里，除了原有的 **DLL 注入（推荐）**，新增 **AppID Changer（轻量）**：

- 做法：在游戏目录写入 `steam_appid.txt`，并用同一身份的环境变量把游戏拉起，游戏退出后**自动还原**原文件（原本没有这个文件就删掉）
- 适用：只认 `steam_appid.txt`、不吃环境变量的游戏；脚本/文件留痕的场景也更好排查
- 和「DLL 注入」一样：填**游戏 AppID** → 点「查询」自动带出程序路径 → 协议 AppID 默认 480（可自定义）→ ▶ 启动、■ 停止
- **下拉会记住你上次选的方式**，两种方式的界面完全一致，只差启动细节
- 万一程序被强杀、断电导致文件没还原：下次打开 OSTGUI 会自动补还原并提示；游戏目录里若残留 `steam_appid.txt`（而你并没有在联机），手动删掉即可

## UI 与交互修复

- **浅色主题下弹窗、弹出菜单不再是深色**：此前程序里"代码动态创建"的弹窗没有跟随应用主题（落到系统主题上，浅色应用 + 深色系统时整片发暗），现已修复；弹窗内的卡片、文字、按钮也统一改用系统原生样式与配色
- 联机页两个分页（内核原生 / 其他）的输入区**文字与样式统一**：统一为「游戏 AppID」「协议AppID」，行距、颜色一致
- 弹窗与菜单背景一律使用系统原生样式（不再自定义着色），深浅主题下观感与系统其它程序一致

## 说明

- 联机的三条路线**一次只用一条**：「内核原生」与「其他」里的两种方式不要同时开
- 480 方案下双方都以 Spacewar(480) 身份运行，好友列表里互相显示"正在玩 480"是正常现象

---

## 升级方式

下载新版解压覆盖旧版程序文件即可。配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。
