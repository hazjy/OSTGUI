# OSTGUI v1.6.2 更新说明

> 适用版本：v1.6.2（对比上一版本 1.6.1）

## 特别说明：

需 **[ZSteamTool v1.1.3](https://github.com/hazjy/ZSteamTool/releases) 及以上**

## 入库管理

- **新增「网格视图」**：页头可切换列表 / 网格；网格卡片是封面 + 游戏名 + AppID + 版本状态 + 同一组操作按钮（都居中排列），宽度固定、自动换行，不随窗口拉伸。
- **卡片悬浮反馈**：鼠标移上去整张卡片轻微放大、浮起一层投影并高亮，移开复原。
- **视图选择按页记住**，重开软件保持上次选的那档。

## 搜索入库

- **同步支持列表 / 网格两档**：与「入库管理」同款切换控件、同尺寸卡片、同一套悬浮反馈，搜索结果也带封面缩略图（仅用于显示，不写缓存）。
- 同样记住上次选的视图。

## 界面

- **进出页面带上浮 + 淡入动画**：系统原生页面过渡，跟随系统"减少动画"设置。
- 浅色主题下卡片补了细描边，卡片边界更清楚。

## 修复
- 无


---

## 升级方式

下载新版解压覆盖旧版程序文件即可。配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。
