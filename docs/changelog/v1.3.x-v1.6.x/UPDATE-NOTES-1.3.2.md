# OSTGUI v1.3.2 更新说明

> 适用版本：v1.3.2（对比上一版本 1.3.1）

## 新功能

- **创意工坊支持**：入库时主游戏行自动附带 Sudama 密钥库中的 AppID 自身密钥（社区通称"创意工坊密钥"）——订阅创意工坊物品后可直接下载，不再报"内容仍处于加密"；
- **设置页日志栏修复**：打开页面即显示历史日志（此前无新日志事件时恒为空白），并加固跨线程刷新链路，消除"运行时日志有时不显示"的问题。

## 维护与内部整理

- 主程序目录更名为 `main/`，构建产物固定于 `main\bin\`，构建脚本自动清理 WindowsAppSDK 产生的冗余嵌套目录；
- 清理一处无任何调用方的死代码。

## 说明

- 已入库的旧游戏如需创意工坊下载，请在应用内重新入库一次（新版本会在 Lua 中自动写入创意工坊密钥），或手动把 Lua 首行补为 `addappid(游戏AppID, 1, "Sudama缓存中该AppID的64位密钥")`；
- 少数限制匿名的创意工坊（部分新 manifest 或开发者限制"仅拥有者"）仍无法绕过，属 Steam 服务端限制。

---

## 升级方式

下载新版解压覆盖旧版程序文件即可。配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。
