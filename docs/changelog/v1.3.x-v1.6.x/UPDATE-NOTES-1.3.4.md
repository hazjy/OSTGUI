# OSTGUI v1.3.4 更新说明

> 适用版本：v1.3.4（对比上一版本 1.3.3）

## 新功能

- **侧边栏宽度可调**：设置 → 外观设置新增「侧边栏宽度」，输入 150–600 之间的数值，点「更改」立即生效，**无需重启应用**。

## 体验优化

- **修复联机页游戏名查询**：此前在联机页输入 AppID 经常查不出游戏名；现在与搜索/入库同源获取，结果秒出；
- **点击空白取消输入框激活**：设置、联机、D加密、S.A.C 页面点击空白处不再误聚焦输入框；已激活的输入框点击空白可正常取消（WinUI 焦点问题的绕行修复，不影响任何按钮/输入框原有操作）。

## 维护与内部整理

- 清理一批无调用方的死代码与无用的配置项（对外行为无任何变化）；
- 移除某些从未启用的设置字段，配置文件更干净（旧配置中的残留字段会被自动忽略）。

## 说明

- 侧边栏宽度也可手动改 `%LOCALAPPDATA%\OSTGUI\config.json` 中的 `NavigationPaneWidth`（150–600），与新增设置等效；
- 自定义侧边栏宽度写入后，旧版程序未识别该设置属正常现象，请使用本版本。

---

## 升级方式

下载新版解压覆盖旧版程序文件即可。配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。
