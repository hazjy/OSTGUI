# OSTGUI v1.8.5 —— 入库提示与界面细节

> 对比 v1.8.4

## 新增

- **用户手册**：`docs/guide/`，安装、入库、库与启动、免 Steam 部署、联机、成就与修改器、设置、故障排查、文件位置共 9 章。

## 修复

- **入库时的「缺密钥」误报减少**：macOS / Linux 专属的 depot以及别的应用共享的公共库 depot 都不再计入。
- **Denuvo授权页「重要说明」重写**：简化了描述。

## 更改

- 窗口顶部留白 48 → 40，界面整体上移一点。
- 「Denuvo」「联机」「模拟器」「修改器」页顶部的分段切换高度统一到 32，整体变薄。

## 升级方式

- 覆盖旧版程序目录即可。
- 内核无需更新。
