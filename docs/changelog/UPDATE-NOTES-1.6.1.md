# OSTGUI v1.6.1 更新说明

> 适用版本：v1.6.1（对比上一版本 1.6.0）

## 特别说明：

需 **[ZSteamTool v1.1.3](https://github.com/hazjy/ZSteamTool/releases) 及以上**

## 搜索入库

- **新增「取消任务」按钮**：点了入库才会出现；点下即中止，已下载的临时清单会一并清理，再点一次入库即可重来。取消期间按钮变「取消中…」并禁用，同一时间只跑一个入库任务。
- **搜索结果卡片改版**：与「入库管理」卡片同构，带封面缩略图（仅用于显示，不写缓存）。
- **「入库」按钮改为纯图标**

## 封面图

- **「入库管理」卡片开始显示封面**：优先读本地缓存，缺了按官方 appdetails 兜底拉取；滚动到可见才加载，不会一次性全拉。
- **封面按显示尺寸重编码后落盘（240×112）**，封面缓存体积约为原来的 1/5。

## 模拟器页

- **新增「一键还原」**：撤掉部署进游戏目录的模拟器产物，回到部署前状态——递归删 `SteamAPICheckBypass.json` 及它带出的 `version.dll` / `winmm.dll` / `winhttp.dll`、删 `steam_interfaces.txt` / `local_save.txt` / `steam_settings` 目录、把 `*.bak` 换回原名。只动游戏目录，不碰别处；有文件被占用时如实报「还原未完成」，不报假成功。存档 `%APPDATA%\GSE Saves\<appid>` 只提示、不删。

## 界面

- 入库数量不再显示在窗口标题栏，改到「入库管理」页标题：**入库管理 「40」**；数量为 0 时不显示括号。

## 修复

- **最大化 / 最小化后关窗，下次启动窗口尺寸与状态错乱**（启动成一条细条，或尺寸超出屏幕）已修。
- **启动初始化偶发失败**（内容区空白、Steam 路径与 DLL 状态为空）已修复，每次启动只初始化一次。
- OnlineHost 现在会写运行日志，联机相关出问题时便于排查。

## 性能

- **入库时的内存占用下降**：读取密钥缓存不再整份展开，单次入库的额外内存从上百 MB 降到几 MB 量级；入库结束后会主动整理一次内存。
- 去掉了一个每 5 秒遍历整个游戏库的后台扫描。

---

## 升级方式

下载新版解压覆盖旧版程序文件即可。配置与缓存位于 `%LOCALAPPDATA%\OSTGUI`，升级不影响。
