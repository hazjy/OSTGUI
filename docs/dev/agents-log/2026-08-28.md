## 关键结论（沉淀于 DEV-NOTES）

- 库页名称查询根因：addappid 全集含 224 个 DLC/depot ID 被当游戏取名，永不成功永不落缓存 → 每次启动重试拖慢；后改为仅主游戏（有独立 Lua 文件）+ 后台静默补名
- DLC 名数据源实证：steamcmd 对 DLC 返回空壳（无 name）；官方 store appdetails 在本机可达且返回 DLC 名（部分 DLC success:false 为数据源限制）
- 名称/时间缓存统一语义：主缓存仅存主游戏；显示名处（联机、DLC）实时查询不参与缓存；30 天 TTL 内改名锁定
