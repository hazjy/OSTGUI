# 09 · 文件位置

> 适用版本：v1.8.4
>
> `<Steam>` = Steam 安装目录；`%LOCALAPPDATA%` = `C:\Users\<用户名>\AppData\Local`。

## OSTGUI 自己的文件

全部在 `%LOCALAPPDATA%\OSTGUI`，与程序目录无关，覆盖升级不受影响。

| 路径 | 内容 | 删除后的影响 |
|---|---|---|
| `config.json` | 设置、清单源密钥、窗口尺寸、视图档位 | 回到默认设置，密钥要重填 |
| `logs\ostgui.log` | 运行时日志，按行数裁剪 | 丢失历史日志 |
| `logs\onlinehost.log` | 联机宿主的日志 | 同上 |
| `covers\` | 入库卡片封面缓存 | 重新下载封面 |
| `achievements\<AppID>.json` | 成就勾选的本地留底 | 未保存到 Steam 的勾选丢失 |
| `cache\achievement-list.json` | 成就页左侧列表缓存 | 重新扫描一次 |
| `trainers\` | 修改器下载目录与 `trainers.json` 索引 | 需重新下载 |
| `bindings.json` | 修改器与游戏的进程绑定 | 绑定丢失 |
| `appid-changer.txt` | 文件会话的还原台账 | 残留的 `steam_appid.txt` 可能不再自动还原 |
| `sudama_cache.json`、`token_cache.json` | Sudama 密钥与令牌的本地缓存 | 重新下载（大文件较慢） |

## Steam 侧的文件

| 路径 | 谁写的 | 内容 |
|---|---|---|
| `<Steam>\config\lua\<AppID>.lua` | OSTGUI 入库 / 编辑 Lua | `addappid`、密钥、`addtoken`、`setManifestid` |
| `<Steam>\config\lua\manifest.lua` | OSTGUI 设置页「请求码源」 | 内核取清单请求码的级联脚本；勾选变化即覆盖，建议先备份 |
| `<Steam>\config\depotcache\` | OSTGUI 入库 | 清单文件，按 `<depot>_<gid>.manifest` 命名 |
| `<Steam>\depotcache\` | OSTGUI 入库（双写） | 同上，Steam 实际读取的位置之一 |
| `<Steam>\logs\content_log.txt` | Steam | 清单与请求码的失败原文 |
| `<Steam>\logs\connection_log.txt` | Steam | 连通性测试（代理异常时先看这里） |
| `<Steam>\opensteamtool\` | 内核 | 内核配置与日志；`opensteamtool.toml` 控制日志级别与某些模式 |
| `<Steam>\dumps\` | Steam | 客户端崩溃转储 |
| `<Steam>\steamapps\libraryfolders.vdf` | Steam | 库目录列表（按 AppID 定位游戏 exe 时用） |

## 内核文件

| 路径 | 内容 |
|---|---|
| `<Steam>\OpenSteamTool.dll` | 内核主体 |
| `<Steam>\dwmapi.dll`、`xinput1_4.dll` | 代理，Steam 启动时加载内核 |

版本号可以从 `OpenSteamTool.dll` 的文件属性里读，「关于」弹窗里的「内核版本」读的也是它。
