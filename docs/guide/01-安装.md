# 01 · 安装

## 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 20H1（19041）及以上，x64 |
| Steam | 已安装并至少登录过一次 |
| 内核 | ZSteamTool 的三个 DLL，手动复制到 Steam 根目录 |
| 运行时 | 无需安装 .NET（发布包为原生编译） |

## 一、部署内核

内核是注入 Steam 的那一层，OSTGUI 只负责界面与配置，不含内核代码。

1. 下载 ZSteamTool 发布包，解压。
2. 打开包内的 `Release\`（日常使用）或 `Debug\`（排查问题用，日志更全）。
3. 把这三个文件复制到 Steam 根目录，即 `Steam.exe` 所在目录：

```
OpenSteamTool.dll
dwmapi.dll
xinput1_4.dll
```

4. Steam 根目录里若已有同名文件，覆盖前先备份（重命名成 `.bak` 即可）。

成功判据：启动 OSTGUI 后，主页「关键DLL」显示 **已注入**；显示「未注入」说明三个文件没有齐全。

> `dwmapi.dll` 与 `xinput1_4.dll` 是代理，Steam 启动时由它们加载 `OpenSteamTool.dll`。三个缺一不可。

## 二、安装 OSTGUI

1. 下载发布包 `OSTGUI-v<版本>.zip`。
2. 解压到任意目录，不要放进 Steam 目录。
3. 运行 `OSTGUI.exe`。

首次启动会自动检测 Steam 安装路径。主页「Steam 状态」显示是否已运行。

## 三、填入清单源密钥

打开设置页「清单源」，至少填一个可用的清单源：

| 源 | 用途 | 需要 |
|---|---|---|
| MHub | 按 depot+gid 下载清单 | API Key，24 小时过期 |
| Hubcap | 按 depot+gid 单份生成清单 | API Key（免费为7日有效期），免费额度普通清单 1500 次/日，创意工坊清单500次/日 |
| Sudama | 只提供 depot 密钥与访问令牌 | 不需要 |

仅 Sudama （密钥&令牌）也能完成入库，清单由内核和请求码兜底获取。一般情况无需主动下载清单，使用请求码即可

## 四、升级

解压新版本，覆盖程序目录即可。新旧版本可以共存。

配置与缓存不在程序目录，覆盖不会丢：见 [09-文件位置](09-文件位置.md)。

## 五、卸载

1. 删除 OSTGUI 程序目录。
2. 若要还原内核：把 Steam 根目录里那三个 DLL 换回之前的备份；没有备份时删除它们，Steam 会回退为原版行为。
3. 配置与缓存在 `%LOCALAPPDATA%\OSTGUI`，按需删除。
