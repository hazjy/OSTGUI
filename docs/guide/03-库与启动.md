# 03 · 库与启动

> 适用版本：v1.8.4

库页读取的是 `<Steam>\config\lua\*.lua`，一次入库一个文件。删除 lua 等于删除该游戏的入库记录。

## 浏览

- 右上角的两个图标切列表 / 网格，档位记住，下次打开保持。
- 顶部输入框按游戏名或 AppID 过滤，随输入实时生效。
- 「刷新」重新扫描 lua 目录。

## 单项操作

右键条目（或卡片菜单）有这些项：

| 项 | 作用 |
|---|---|
| 编辑 Lua | 打开内置编辑器，见下 |
| 复制 AppID / 复制游戏名称 | 复制到剪贴板 |
| 切换版本模式 | 在「固定版本」与「自动更新」之间切换，见下 |
| 补齐版本配置 | 把 Lua 里缺少的 `setManifestid` 补上 |
| 删除 | 删除该游戏的 lua（清单与密钥文件不删） |

## 版本模式

卡片上显示「固定版本」或「自动更新」，旁边的按钮可切换。

- **自动更新**：Lua 里没有生效的 `setManifestid`，游戏跟着 Steam 更新。
- **固定版本**：Lua 里写入 `setManifestid(depot, "gid", 大小)`，内核锁住该版本。游戏更新后仍按旧清单启动。

切换前会检查 depot 是否全覆盖：有 depot 缺配置时无法切到固定版本，此时先点「补齐版本配置」。补齐写入的是当前版本的 gid。

## 编辑 Lua

库页点「编辑 Lua」进入编辑器：

- 语法高亮，底部状态栏显示行:列。
- 上方按钮快速插入 `addappid(AppID)`、`addappid(depot, 1, "密钥")`、`addtoken(AppID, "令牌")`、`setManifestid(depot, "gid", 大小)`。
- 「注释/取消」给选中行加或去掉 `-- ` 前缀。
- 保存后写回 `<Steam>\config\lua\<AppID>.lua`，内核监听文件变化并热重载，不需要重启 Steam。

保存成功会弹一条通知：`<AppID>.lua 已写入，内核将自动热重载`。

## 启动游戏

从 Steam 库里启动。启动前的准备由内核在 Steam 进程内完成，不需要 OSTGUI 保持打开。

几种常见现象：

- 启动后立刻退出：多半是缺密钥或缺清单，见 [08-故障排查](08-故障排查.md)。
- 能进主菜单但联机功能异常：会话身份问题，见 [05-联机](05-联机.md)。
- 从未打开 Steam 也能玩：那是「免 Steam 部署」，见 [04-免Steam部署](04-免Steam部署.md)。
