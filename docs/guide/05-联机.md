# 05 · 联机
* 内置的联机功能未必对所有游戏有效，有时你仍需联机补丁。
> 适用版本：v1.8.4
>
> 位置：左侧「联机」页。三条路线，一次只用一个。

## 前置条件

1. Steam 在线并已登录。
2. 内核三个 DLL 已部署（[01-安装](01-安装.md)）。
3. 目标游戏已入库（lua 里有 `addappid`）。
4. 对端使用相同的会话身份，否则双方互相看不到房间。

「其他」页下方有三个勾，就是前三项的状态，每 2 秒刷新一次，点「查询」时也会刷新。

## 从哪条路线开始

| 路线 | 入口 | 适用 |
|---|---|---|
| 宿主会话 | 「其他」→ 宿主会话（推荐） | 大多数情况，优先使用 |
| 命令行会话 | 「命令行会话」 | 嗯...如果你愿意的话（似乎没什么优点） |
| 文件会话 | 「其他」→ 文件会话 | 第二选择 |

三条路线的机制不同；只能同时运行一个联机会话。

## 宿主会话（推荐）

1. 「其他」→ 选「宿主会话（推荐）」。
2. 「游戏 AppID」填已入库游戏的 AppID，点「查询」确认。
3. 「协议AppID」保持「默认（480）」。480 是 Valve 的联机测试用 App，任何人都能安装。
4. 点「启动游戏」。

宿主进程先以会话身份初始化 Steam，再把游戏作为子进程拉起，游戏自身的大厅、P2P、叠加层身份一致。结束后点「停止游戏」，游戏与宿主一起结束。

## 命令行会话

1. 选「命令行会话」。
2. 填「游戏 AppID」→「查询」。
3. 点「启动联机」；结束时点「停止游戏」。

这条路线让 Steam 以 `-applaunch <AppID> -onlinefix=<会话 AppID>` 启动游戏，会话身份由内核改写。首次使用前先安装 Spacewar：浏览器打开 `steam://install/480`。

## 文件会话

同一入口下选「文件会话」，操作同宿主会话。

它在游戏 exe 同目录写入 `steam_appid.txt`，并给进程设置会话身份的环境变量，退出后按台账还原。中途异常退出留下的残留，OSTGUI 下次启动时会补还原。

## 协议 AppID

默认 480。 480 没有手柄配置，需要改用自带 Steam Input 配置的免费 AppID，选「自定义」并填该 AppID。

## 常见现象

- 双方都启动了，但看不到房间：确认两边协议 AppID 相同；确认对端也用同一路线。
- 命令行会话能弹出邀请但进不去：改用宿主会话，如果还是不行你可能要使用联机补丁。
- 启动后弹窗报错或直接退出：见 [08-故障排查](08-故障排查.md)。
