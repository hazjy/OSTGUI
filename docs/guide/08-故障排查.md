# 08 · 故障排查

> 先看日志再动手。日志在 `%LOCALAPPDATA%\OSTGUI\logs\ostgui.log`，设置页「运行时日志 → 打开日志文件夹」可直达。Steam 侧日志在 `<Steam>\logs\`。

## 按症状查

| 症状 | 先看 | 常见原因 |
|---|---|---|
| 主页「关键DLL」显示缺少关键DLL | Steam 根目录 | 三个 DLL 没齐、放错了目录、或 Steam 装在别的盘 |
| 库页看不到刚入库的游戏 | 日志有无 `已生成 Lua 文件` | 没生成 lua；设置页「Lua 路径」被改错；库页没刷新 |
| 入库提示「缺失密钥」 | 下载阶段是否卡住 | 警告按"有清单但无 key"判定，公开 depot 会误报；真缺时下载阶段报"内容仍处于加密"或初始化失败，只能等密钥库收录 |
| 入库提示「缺失清单」 | `清单源级联顺序`、各源的状态码 | 源没配 key、key 过期（MHub 24 小时）、额度用尽（Hubcap 429） |
| 下载时提示「无互联网连接」，实际网络正常 | `<Steam>\logs\content_log.txt` | 清单缺失或请求码取不到，Steam 把失败报成连接问题（见下一行） |
| `content_log` 出现 `Failed to get manifest request code` | 设置页「请求码源」的测活结果 | 全部源被关掉、`manifest.lua` 被自定义内容覆盖、所选源当时不可用 |
| D 加密游戏启动弹窗报错、关掉后退出（不是闪退） | 弹窗里的错误码、内核日志 | Denuvo 票据或授权问题：`88500012` 为陈旧票据，`88500005` 属反篡改处罚（见 Denuvo 页）。缺密钥不走这个症状，它在下载阶段就失败 |
| 联机看不到房间 | 联机页三个前置勾 | 对端协议 AppID 不同、游戏未入库、Steam 未登录 |
| 免Steam 部署后联机失效 | 模拟器页日志 | 部署改写了游戏目录，联机前先「一键还原」 |
| 报网络错误但浏览器正常 | `<Steam>\logs\connection_log.txt` | 本机代理异常。先看 `Got HTTP 502` / `ConnectFailed`，再决定换节点或关代理 |

## 判断清单源可用性

设置页「清单源」每行有「测活」，用一组固定的 depot+gid 单独请求该源，结果显示在「连通性」。

- 401 / 403：密钥无效或过期，重新获取。
- 429：当日额度用尽，等第二天或换源。
- 200 但入库仍失败：该源没有这个 gid，换源，或让内核运行时按请求码取。

请求码源的「测活」在「请求码源」区，同样是单源请求，不消耗清单源额度。

## 判断内核是否在工作

1. 主页「关键DLL」为「就绪」。
2. Steam 根目录存在 `opensteamtool\` 目录（内核自己写的）。
3. Debug 版内核会在 `opensteamtool\*.log` 写日志；Release 版不写，只能靠行为确认。

第 3 条的含义：Debug 版日志文件为空，说明对应代码路径没有执行过；文件在每次 Steam 启动时重建，看到的只是本次会话。

## 提交问题时的信息

附上这些，比描述现象有用：

- `%LOCALAPPDATA%\OSTGUI\logs\ostgui.log`（可截取最后 100 行）
- `<Steam>\logs\content_log.txt` 中报错前后几行
- 游戏 AppID、使用的清单源、`OSTGUI 版本` 与 `内核版本`（「关于」弹窗）
