# OSTGUI 用户手册

> 面向使用者。开发与机制文档在 `docs/dev/`，逐版本改动在 `docs/changelog/`。

## 最短路径

1. 把内核三个 DLL 复制到 Steam 根目录（见 [01-安装](01-安装.md)）。
2. 解压发布包，运行 `OSTGUI.exe`。
3. 设置页「清单源」填入 MHub 或 Hubcap 的 API Key（不填只能拿到密钥与令牌，下载不到清单）。
4. 搜索入库，等待「入库完成」。
5. 库页确认游戏已列出，从 Steam 启动。

## 写法约定

- 路径里的 `<Steam>` 指 Steam 安装目录，`<AppID>` 指游戏 AppID。
- 界面文字用「」标出，代码、文件名、路径用 `等宽字体`。
- 每个操作后给出成功判据：界面上应看到什么，或日志里应出现哪一行。
- 截图随版本更新，位置在 `docs/guide/images/`，暂缺。
