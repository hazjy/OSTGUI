# 06 · 成就与修改器

> 适用版本：v1.8.4

## 成就

位置：左侧「成就」页。需要 Steam 在线。

### 读取

1. 页面顶部副标题提示「需要 Steam 在线；单击「保存到 Steam」后才会实际生效」。
2. 左侧列表有两个来源：「lua」列出已入库的游戏，「正版」列出 Steam 客户端认为你拥有的游戏。两个都可以勾，同时显示。
3. 「AppID/名称」可按 AppID 或名称过滤，右侧输入框按成就名称或描述过滤。
4. 列表不新鲜时点「重新扫描游戏列表」。

### 编辑与保存

1. 选中游戏，右侧列出成就。
2. 「全部解锁」「全部锁定」批量改。 「从 Steam 读取」需要 Steam 在运行：把 Steam 客户端里当前的成就状态读回来并写入本地留底；客户端里没有该游戏的成就数据时只提示，保留本地留底。
3. 勾选只写本地留底：`%LOCALAPPDATA%\OSTGUI\achievements\<AppID>.json`。
4. 点「保存到 Steam」才真正写入。写入过程会启动一个短命子进程，完成后弹提示。

### 已知现象

- Lua游戏在重启 Steam 后修改的成就仍在，但更新或卸载游戏可能使成就丢失。
- 内核会对入库游戏清空 819 通道里的成就数据，成就页可能显示不出来。这是显示层问题，不代表没写进去。
- 部分游戏的成就定义不在本地 `UserGameStatsSchema_<AppID>.bin` 里，页面会是空的，无法编辑。

## 修改器

位置：左侧「修改器」页。目录来自风灵月影站点。

### 下载

1. 上方分段切「搜索」，在「游戏名称（英文）」里填英文名搜索，结果显示「修改器名称」。
2. 点「下载」；已下载的条目切到「已下载」分段管理，可「更新」「删除」「启动」「打开所在目录」。
3. 下载目录可改；留空时用 `%LOCALAPPDATA%\OSTGUI\trainers`。

### 进程绑定

绑定后，游戏启动时自动启动修改器，游戏退出时结束由 OSTGUI 启动的那个修改器进程。

1. 在「已下载」里选中条目，右侧「进程绑定」区点「添加绑定」，选择游戏 exe。
2. 绑定写入 `%LOCALAPPDATA%\OSTGUI\bindings.json`。
3. 点「运行」启动监控进程。监控进程独立于界面：**关掉 OSTGUI 后仍会按绑定起停修改器**。
4. 「停止」结束监控进程；绑定保留，下次可再运行。

> 不运行监控进程时，绑定不生效，修改器只能手动「启动」。
